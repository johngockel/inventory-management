Architektur: Factory Inventory Management

Full-Stack-Demo mit Vue 3 im Frontend, FastAPI im Backend und In-Memory-Daten aus JSON-Dateien. Es gibt keine Datenbank.

1. Systemarchitektur

Browser / Frontend

Vue 3 SPA, Vite Dev-Server, Port 3000
  • Vue Router (History-Modus)
  • Views pro Seite
  • Axios-Client in api.js
→HTTP/JSON
GET, POST, PATCH, DELETE

Backend / API

FastAPI, Uvicorn, Port 8001
  • Routen unter /api/*
  • Pydantic-Modelle für Antworten
  • Filterung in Python, CORS offen
→Laden beim Start

Daten

server/data/*.json
  • mock_data.py lädt alle Dateien
  • Daten liegen im Speicher
  • Änderungen gehen beim Neustart verloren

Die Vue-Anwendung spricht direkt mit der API auf http://localhost:8001/api. Es gibt keinen Proxy und keine Authentifizierung.

3. Datenfluss

  1. Der Benutzer ändert einen Filter in der FilterBar oder wählt einen Zeitraum. Der Zustand liegt in useFilters.js.
  2. Eine View oder App.vue ruft eine Methode in api.js auf. Leere Filterwerte (all) werden dort nicht als Query-Parameter gesendet.
  3. Axios sendet eine GET-Anfrage an /api/... auf Port 8001.
  4. FastAPI nimmt die Query-Parameter entgegen. Die Funktionen apply_filters und filter_by_month filtern die In-Memory-Listen auf Kopien.
  5. Pydantic validiert die Antwort gegen das response_model.
  6. Die Antwort wird in ref-Variablen gespeichert, zum Beispiel allOrders oder inventoryItems.
  7. Abgeleitete Werte wie Kennzahlen, Diagramme und Tabellen sind computed-Properties. Sie aktualisieren sich automatisch, wenn sich Filter oder Rohdaten ändern.

Bekanntes Problem: fehlende Endpunkte

Das Frontend ruft in api.js die Pfade /api/tasks (GET, POST, PATCH, DELETE) und /api/purchase-orders (GET, POST) auf. Diese Routen existieren in server/main.py nicht. Der laufende Server antwortet darauf mit HTTP 404.

Betroffen sind das Aufgaben-Modal (TasksModal.vue) und die Erstellung von Bestellungen aus dem Backlog im Dashboard. Diese Funktionen können nicht korrekt arbeiten, bis die Endpunkte im Backend ergänzt werden.

7. Entwicklung starten

Backend: cd server && uv run python main.py (API-Doku: http://localhost:8001/docs)

Frontend: cd client && npm install && npm run dev (http://localhost:3000)
